# lumawen-guitars

Open-source guitar designs built around Lumawen hexaphonic pickups.

## Status

Early design. Nothing here is ready to build yet. Watch the repo or join the Discord to follow along.

## What's here

- `body/` and `neck/`: drawings and CNC files
- `wiring/`: wiring diagrams for the hexaphonic pickups
- `docs/`: build guide, parts list and photos
